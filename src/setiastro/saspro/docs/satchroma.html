Saturation / Chroma Tool

Hue-selective colour strength: a draggable curve over the hue wheel scales saturation (HSV) or chroma (CIELAB) per hue, so you can lift one colour and calm another independently. Split before/after preview; nothing touches the image until Apply.

1. Using the tool

The curve runs left-to-right across the hue wheel (0°–360°, with the colour strip beneath it); its height is a per-hue multiplier — 1× is neutral, above 1 boosts that hue, below 1 mutes it, 0 removes its colour. Drag the curve where a hue lives to target it.

Shaping the hue curve

  • Drag a point up/down to boost or cut that hue's colour strength (0–3×); drag left/right to move which hue it targets.
  • Click empty space to add a point; double-click a point (or right-click → Delete) to remove it.
  • Linked endpoints — the first and last points are the same hue (red at 0° = 360°), so they move together and the curve wraps seamlessly around the wheel.
  • Reset Curve returns every hue to 1× (no change).

2. Technical details

A hue→multiplier curve drives a per-pixel scaling of either HSV saturation or CIELAB chroma. Everything runs on float RGB in [0,1].

2.1 The hue-selective multiplier

The control points are interpolated with a monotone PCHIP spline into a 4096-entry lookup table over normalised hue h ∈ [0,1] (= 0°–360°). The global strength scales it, giving each pixel's hue a multiplier:

m(h)=\mathrm{strength}\cdot\mathrm{LUT}[h]\,,\qquad m\in[0,3]

Because the two end control points are the same hue, the curve is periodic around the wheel — no seam at red.

2.2 Saturation mode (HSV)

The image is converted to HSV; each pixel's saturation is scaled by the multiplier for its hue and re-clamped:

S'=\mathrm{clip}\!\left(S\cdot m(h),\;0,\;1\right)

This is fast and intuitive, but HSV saturation is not perceptually uniform — large boosts can drift hue and lightness. For clean colour work, prefer Chroma mode.

2.3 Chroma mode (CIELAB)

The image is converted to CIELAB. sRGB is first linearised,

\mathrm{lin}=\left(\frac{c+0.055}{1.055}\right)^{2.4}\ (c>0.04045),\qquad \mathrm{lin}=\frac{c}{12.92}\ (\mathrm{else})

then taken to XYZ (D65) and to Lab with

L^{*}=116\,f\!\left(\frac{Y}{Y_n}\right)-16
a^{*}=500\left(f\!\left(\frac{X}{X_n}\right)-f\!\left(\frac{Y}{Y_n}\right)\right),\qquad b^{*}=200\left(f\!\left(\frac{Y}{Y_n}\right)-f\!\left(\frac{Z}{Z_n}\right)\right)
f(t)=t^{1/3}\ (t>0.008856),\qquad f(t)=7.787\,t+\frac{16}{116}\ (\mathrm{else})

The pixel's hue is the angle of its colour in the a*–b* plane, and the multiplier scales the chroma radius while leaving lightness and hue untouched:

h=\frac{1}{2\pi}\,\mathrm{atan2}(b^{*},a^{*})\ \ (\mathrm{mod}\ 1)
(a^{*},b^{*})\;\to\;(a^{*},b^{*})\cdot m(h)

Because only the radius changes, Chroma mode boosts colour strength without the hue drift or lightness shift that HSV saturation can introduce — the reason it's the better choice for strong, clean saturation moves.

2.4 Masking

With Respect active mask on, the result is blended back against the original over the mask:

\mathrm{out}=\mathrm{mask}\cdot\mathrm{out}+(1-\mathrm{mask})\cdot\mathrm{src}

2.5 Notes

  • The preview runs on a downsampled ROI (longest side capped) for responsiveness; Apply recomputes the full-resolution image on a worker thread and never modifies the document until then.
  • HSV conversions use OpenCV when available (colorsys fallback); Lab uses scikit-image when available (a built-in sRGB↔Lab fallback otherwise).
  • The grip/headless preset stores the mode, curve points, strength and mask setting, so a dropped shortcut reproduces the exact adjustment.
