Filter / Sensor Curve Manager

One place to add, label, edit, share and delete the filter and sensor response curves that SPCC and SSSC use. Open it from the Filter / Sensor Curves… button in either tool, or from Functions → Color Calibration → Filter / Sensor Curve Manager.

SASpro ships with close to 200 filter and sensor curves, but new filters and sensors appear all the time. If yours isn't listed, the fastest route is usually: find the manufacturer's transmission or QE chart, take a screenshot, and use Digitize Image…. It takes about a minute per curve.

The window

  • Library (left): My curves, then the built-in filters grouped by maker, then the built-in sensors. Type in the search box to filter by name, maker, channel or category. Select several curves to overlay and compare them. Double-click a curve to open it in the editor.
  • Plot (top right): the selected curves, plus the curve you are editing (thick yellow).
  • Curve editor (bottom right): the point table, the labels, live checks, and Save to My Curves (Ctrl+S).

When you open the manager from SPCC or SSSC, your current R/G/B, sensor and LP/cut choices are pre-selected, so your whole optical chain is already plotted.

Four ways to get a curve in

1 · Paste Data

Copy two or more columns from Excel, a web page, a PDF table or a text file, then click Paste Data (or press Ctrl+V in the table). Tab, comma, semicolon or space delimiters, decimal commas, % signs and header rows are all handled. Units are detected and converted for you:

  • wavelengths in Å (median > 2000) or µm (median < 5) are converted to nm;
  • a response that goes above 1.5 is treated as percent and divided by 100.

If the data has more than one response column (say, wavelength plus the R, G and B QE of a color sensor), you pick the columns and every checked column becomes its own curve. They load one at a time: save the first, and the next appears with the maker and model carried over and the channel guessed from the column name.

2 · Import File…

The same reader, for .csv, .txt, .tsv or .dat files. A .fits file is treated as a curve pack (see below). CSVs exported from the Curve Manager carry their labels in # key: value comment lines, and those labels come back on import.

3 · Digitize Image…

Turns a chart into numbers. Open, paste (Ctrl+V) or drag in the image: a datasheet screenshot (Win+Shift+S / Cmd+Ctrl+Shift+4), a scan, or a web graphic.

  1. Calibrate the axes. Click a labelled tick on the wavelength axis for X1 and type its value. Do the same for a second tick, far from the first, for X2. Then do two ticks on the response axis for Y1 and Y2 (for example 0 and 100). Set whether the response axis is in percent or 0–1. A green grid is drawn from your calibration; if it sits on the chart's own grid, the calibration is right. The markers can be dragged to fine-tune them, using the magnifier under the preview. Slightly rotated scans are fine.
  2. Trace by color. Click on the curve line. The trace starts where you clicked and follows that line both ways, column by column, inside the dashed plot-area box. The box is found automatically on the chart's axes; redraw it to keep a legend out. Gridlines and frame lines are ignored, even when they are the same color as the curve, and a filter's blocked region lying on the 0 % axis is followed. If several curves share one color (a black-and-white datasheet), click the one you want. Raise the tolerance if parts of the line are missing, or lower it if a neighbouring curve gets picked up. Erase Traced Points removes stray bits with a box.
  3. …or click points by hand. Add / Move Points, then click along the curve. The corners, peaks and band edges are enough, and Smooth curve joins them. Drag a point to move it, right-click to delete it. Hand points can also patch a gap in a traced curve.

Many charts show R, G and B (or several filters) together. Trace the first curve, click Keep & Trace Another, and click the next line; the calibration stays. Use Curve sends every kept curve to the editor, one after another, with the channel guessed from the line color.

If the trace goes astray, click the curve again somewhere clean; the trace restarts from that point. If it jumps onto a legend or text, Erase or a tighter box fixes it. Clearing the box entirely is rarely a good idea for a black curve: the axis labels are black too.

4 · Generate Bandpass…

For filters where the maker only publishes specs. Add one row per passband: center wavelength (CWL), FWHM, peak transmission and edge sharpness (1 = Gaussian, 3–6 ≈ a typical interference filter, 15+ ≈ rectangular). The quick-add buttons drop in Hα, Hβ, O III, S II and N II rows at your default FWHM, plus a 400–700 nm broadband box. A dual- or tri-band filter is simply several rows. The FWHM is exact for any sharpness.

Labels

FieldWhat it's for
TypeFilter curves appear in SPCC's and SSSC's R/G/B and LP/Cut lists; Sensor (QE) curves appear in SPCC's Sensor list.
CategoryRGB channel, luminance / UV-IR cut, light-pollution, narrowband, dual / multi-band, OSC color channel (sensor × CFA), photometric band; or sensor QE / ideal reference.
ChannelR, G, B, L, Hα, Hβ, O III, S II, N II, multi-line…
Maker / ModelManufacturer and product. With Auto on, the curve's name is built from these, e.g. ANTLIA_V-PRO_SERIES_R, matching the built-in naming.
Source link / NotesWhere the data came from. This is worth filling in when you plan to share the curve.

The checks under the form flag common problems as you go: wavelengths that look like Å or µm, percent values, negative values, and a filter that doesn't fall to zero at its ends. Outside a curve's range, SPCC treats it as 0 (fully blocking). The Tools menu fixes most of these: sort, resample, smooth, trim, clip to 0–1, normalize the peak, and convert units. Undo (Ctrl+Z) steps back through edits.

Editing, deleting, sharing

  • Built-in curves are never changed. Open in Editor on a built-in starts a copy (…_MOD) that you save under its own name.
  • Renaming one of your curves asks whether to rename it or save a new copy. Saving over an existing name always asks first.
  • Delete works on your own curves only. Each save or delete keeps the previous file as usercustomcurves.fits.bak.
  • Export the selected curves as CSV, or as a curve pack (.fits) that someone else adds with Import Pack…, with all labels intact. Sending a pack is also the easiest way to suggest a curve for the built-in library.

Where curves are stored

Your curves live in usercustomcurves.fits in SASpro's app-data folder: one table per curve, WAVELENGTH in Å plus THROUGHPUT 0–1, the same layout as the built-in SASP_data.fits. The labels are extra header cards (CURVCAT, CHANNEL, MAKER, MODEL, REFURL, NOTES). Curves you added with the old SPCC / SSSC buttons are still there and open in the editor like any other.
